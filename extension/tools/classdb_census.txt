# One row per registered class: `<Class> stay`, `<Class> retire:ZT-n`, or
# `<Class> internal <reason>` (ZD-26). retire's unit is the track whose
# crossing deletes the registration. internal is
# GDREGISTER_INTERNAL_CLASS: a class a C++ core constructs and GDScript
# never names, kept off the script-visible surface without waiting on the
# unit that would otherwise unregister it. check_classdb_census.py refuses
# a registration with no row and reports a row with no registration as
# STALE.

# holder in the permanently-GDScript tier (§9: the compat adapters, the
# kit, the authoring tier). A class the permanent keep set reaches names
# its holding file in the row itself (ZD-34). The default for scaffolding
# is retire.
