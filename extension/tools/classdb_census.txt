# CORRECTED 2026-09-02 [OWNER]: `internal` IS RETIRED AS A DESTINATION.
# GDREGISTER_INTERNAL_CLASS leaves a class in ClassDB.get_class_list() with
# every bound member intact, so it hides the class from the editor without
# removing it from the surface, and the engine uses it ONCE in its whole
# source tree. A class now either STAYS published, or it de-Objectifies into
# a plain C++ class and leaves ClassDB entirely. Existing `internal` rows are
# a way-station to be converted, not a resting state.
#
# The ClassDB disposition ledger (ring-0 plan §2.9 as data, per ZD-15).
# One row per registered class: `<Class> stay`, `<Class> retire:ZT-n`, or
# `<Class> internal <reason>` (ZD-26). retire's unit is the track whose
# crossing deletes the registration. internal is
# GDREGISTER_INTERNAL_CLASS: a class a C++ core constructs and GDScript
# never names, kept off the script-visible surface without waiting on the
# unit that would otherwise unregister it.
#
# NOTHING MECHANICAL CHECKS THIS FILE, and that is accepted. It was a
# completeness ledger while the registered set was shrinking toward a
# number; it is now the written disposition per class, which is a thing a
# person reads and a script cannot judge. A row is worth exactly the
# argument written in it, and a registration whose row is missing is a
# class nobody argued for. Add the row in the slice that adds the
# GDREGISTER, and delete it in the slice that removes one.
#
# stay requires an argument: a §2.9 prose clause, a published contract
# type (a seam twin's return, an option record, a kit-facing record), or a
# holder in the permanently-GDScript tier (§9: the compat adapters, the
# kit, the authoring tier). A class the permanent keep set reaches names
# its holding file in the row itself (ZD-34). The default for scaffolding
# is retire.
