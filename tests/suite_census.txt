# The GDScript suite disposition ledger (ring-0 plan of record ZT-5).
# One row per GDScript suite file under tests/: `<path> keep <reason>` or
# `<path> port <band>`. A suite is a .gd whose first `extends` names
# NetwTestSuite or GdUnitTestSuite.
#
# keep requires an argument, and the only admissible arguments are the
# clauses of the plan's §9 (what stays GDScript forever). port names the
# band whose crossing writes the native law and deletes the suite, and it
# is the DEFAULT: a suite with nothing to argue is debt.
#
# check_suite_census.py refuses a suite with no row and reports a row with
# no suite as STALE, so the slice that deletes a suite deletes its row and
# a forgotten row stays visible.
