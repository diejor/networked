# The GDScript suite disposition ledger (ring-0 plan of record ZT-5).
#
# One row per GDScript suite file under tests/: `<path> boundary <reason>`
# or `<path> port <band>`. A suite is a .gd whose first `extends` names
# NetwTestSuite or GdUnitTestSuite.
#
# boundary requires an argument, and the only admissible arguments are the
# clauses of the plan's §9. A boundary row records WHERE THE LINE SITS
# TODAY and is NEVER a reason to stop a migration (ZD-50): re-argue or
# drop it in the slice that needs to cross it.
#
# port names the band whose crossing writes the native law and deletes the
# suite, and it is the DEFAULT: a suite with nothing to argue is debt.
#
# check_suite_census.py refuses a suite with no row and reports a row with
# no suite as STALE, so the slice that deletes a suite deletes its row and
# a forgotten row stays visible.
