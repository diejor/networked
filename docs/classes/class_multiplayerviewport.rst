MultiplayerViewport
===================

**Inherits:** :godot:`SubViewport`

A :godot:`SubViewport` that runs its own multiplayer session.

.. rst-class:: classref-introduction-group

Description
-----------

Its children use :ref:`api<class_MultiplayerViewport_property_api>` as :godot:`Node.multiplayer <Node#class_Node_property_multiplayer>` and live in its own worlds, so two of them in one process never see or touch each other. Show one with a :ref:`StretchViewportContainer<class_StretchViewportContainer>`.

::

    var seat := MultiplayerViewport.new()
    seat.add_child(preload("res://main.tscn").instantiate())
    $SplitScreen/Left.add_child(seat)
