WebRTCTestSupport
=================

**Inherits:** :godot:`RefCounted`

Erases the benign native WebRTC teardown error from a running framework.

.. rst-class:: classref-introduction-group

Description
-----------

Tearing down a connected WebRTC session, either when the retry path replaces a stale peer or on close, makes libdatachannel log ``SctpTransport::sendReset ... errno=2`` on Linux. That is a harmless ``ENOENT`` on an already-gone stream, and it is the only error this helper claims is benign. A framework that records engine errors would otherwise report it as a failure of whatever test happened to be running.

::

        WebRTCTestSupport.erase_benign_error = my_framework_eraser
        # ... after any WebRTC teardown
        await WebRTCTestSupport.clear_optional_sctp_reset_error()

:godot:`Callable` **erase_benign_error** = ``Callable()`` :ref:`🔗<class_WebRTCTestSupport_property_erase_benign_error>`

Erases a recorded error the running framework would otherwise report as a failure, as ``func(Array[String]) -> void``.  Injected the way :godot:`NetwGameHarness.reporter <NetwGameHarness#class_NetwGameHarness_property_reporter>` is, because reaching into a framework's error monitor is the framework adapter's business and this file runs under any framework or none. Left unassigned it erases nothing, which is the right answer for a caller whose framework records no errors.
