NakamaIdToken
=============

**Inherits:** :ref:`NetwIdToken<class_NetwIdToken>` **<** :ref:`NetwAccountProvider<class_NetwAccountProvider>` **<** :godot:`RefCounted`

Proves a player's Nakama account to a server over ENet or WebRTC, with a join token the Nakama server signs.

.. rst-class:: classref-introduction-group

Description
-----------

The server runs ``addons/networked_nakama/server/networked.js`` with its private key, the game includes the matching public key, and a signed in :ref:`NakamaAccount<class_NakamaAccount>` fetches the tokens.

::

    const JOIN_KEY := "res://join_token.pub"

    func _init() -> void:
        Netw.configure_admission(admit).accept(NakamaIdToken.new(JOIN_KEY))

    func admit(request: NetwJoinRequest) -> Error:
        return OK if request.account else ERR_UNAUTHORIZED
