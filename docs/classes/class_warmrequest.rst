WarmRequest
===========

**Inherits:** :godot:`RefCounted`

A single table's cache-warming intent, produced by a :ref:`WarmPolicy<class_WarmPolicy>`.

.. rst-class:: classref-introduction-group

Description
-----------

A request is a value naming what a write-behind backend should pre-load for one table. Synchronous backends ignore it. :ref:`kind<class_WarmRequest_property_kind>` decides which of :ref:`id_list<class_WarmRequest_property_id_list>` or :ref:`filter_map<class_WarmRequest_property_filter_map>` carries the scope, and the four static factories are the only way to get a request whose scope and kind agree.

::

    # Warm everything in the table:
    WarmRequest.all()
    # Warm a known set of records:
    WarmRequest.ids([&"valeria", &"jose"])
    # Warm by a column filter:
    WarmRequest.filter({ &"online": true })
    # Warm nothing eagerly (lazy fetch-on-miss still applies):
    WarmRequest.none()

\ Calling ``new()`` instead gives the same request :ref:`none()<class_WarmRequest_method_none>` answers.
