NetwDefaultJoin
===============

**Inherits:** :godot:`RefCounted`

The join handler a session falls back to when a game registered none, spawning the joining player at the template the client named.

.. rst-class:: classref-introduction-group

Description
-----------

Used when a session declared no handler of its own through :ref:`Netw.configure_join()<class_Netw_method_configure_join>`. It puts a joining player into a scene and spawns them at the template the client named, which resolves to a :ref:`SpawnSlot<class_SpawnSlot>`.

A client sends ``(scene_stem, spawner_path)`` as its join arguments, and those are :ref:`spawn()<class_NetwDefaultJoin_method_spawn>`'s parameters after the :ref:`NetwParticipant<class_NetwParticipant>` every handler takes first. A game wanting a different arrangement declares its own handler with :ref:`Netw.configure_join()<class_Netw_method_configure_join>`.

::

    api.session_prepare_join(username, [&"Arena", ^"Player"])
    api.multiplayer_peer = peer

:ref:`NetwPromise<class_NetwPromise>` **spawn**\ (\ participant\: :ref:`NetwParticipant<class_NetwParticipant>`, scene_stem\: :godot:`StringName`, spawner_path\: :godot:`NodePath`\ ) :ref:`🔗<class_NetwDefaultJoin_method_spawn>`

Activates ``scene_stem``, resolves the template at ``spawner_path``, and adds the node ``participant`` plays. The returned promise settles with the entered :ref:`NetwSceneHandle<class_NetwSceneHandle>`.

\ ``scene_stem`` is the registered scene name used by :ref:`NetwMultiplayer.scene_find()<class_NetwMultiplayer_method_scene_find>`, not a ``res://`` path or ``uid://`` reference.

A persistence hydration the player's engine asked for completes before the player is seated, so a returning player enters with its saved state already applied. That hydration is why this returns a promise rather than the handle. See :ref:`NetwMultiplayer.scene_activate()<class_NetwMultiplayer_method_scene_activate>` and :ref:`NetwMultiplayer.scene_find()<class_NetwMultiplayer_method_scene_find>`.

A game that restores a player to whichever scene it left from registers its own handler with :ref:`Netw.configure_join()<class_Netw_method_configure_join>` and reads that scene itself, because only the game knows where it recorded one.

\ **Server Only.**
