NetwPersistence
===============

**Inherits:** :godot:`RefCounted`

One :ref:`NetwEntity<class_NetwEntity>`'s saved record, reached as :ref:`NetwEntity.persistence<class_NetwEntity_property_persistence>`.

.. rst-class:: classref-introduction-group

Description
-----------

The server reads the :ref:`NetwPersistenceConfig<class_NetwPersistenceConfig>` and saved properties when the root is ready. Wait for :ref:`loaded<class_NetwPersistence_signal_loaded>` before using stored values.

::

    @onready var entity: NetwEntity = NetwEntity.of(self)

    func _ready() -> void:
        entity.persistence.loaded.connect(on_loaded)

    func on_loaded(_found: bool) -> void:
        show_contents()

\ :ref:`NetwPersistenceConfig.interval()<class_NetwPersistenceConfig_method_interval>` saves changed values automatically. Freeing the root saves one last time. Failed loads and saves emit :ref:`NetwDatabase.failed<class_NetwDatabase_signal_failed>`.

.. _class_NetwPersistence_method_load:

.. rst-class:: classref-method

:ref:`NetwPromise<class_NetwPromise>` **load**\ (\ ) :ref:`🔗<class_NetwPersistence_method_load>`

Reads the stored record and applies it to the configured properties. The promise returns ``true`` when a record was found, and ``false`` when none was stored and the properties keep their values. A failed load fails the promise, and :ref:`NetwPromise.wait()<class_NetwPromise_method_wait>` returns the code.

.. code:: text

    Error
    ┠╴ERR_UNCONFIGURED       no persistence, unopened database or missing migration
    ┠╴ERR_UNAUTHORIZED       this peer is not the server
    ┠╴ERR_BUSY               a save is pending, properties have unsaved changes,
    ┃                        changed during loading or too many operations are pending
    ┠╴ERR_DOES_NOT_EXIST     a configured node was freed during loading
    ┠╴ERR_FILE_UNRECOGNIZED  unknown save format or a newer saved version
    ┠╴ERR_INVALID_DATA       saved property names or types differ
    ┠╴ERR_UNAVAILABLE        the database closed or the session ended during loading
    ┖╴storage error         storage could not read the record

\ **Server Only.**

.. _class_NetwPersistence_method_save:

.. rst-class:: classref-method

:ref:`NetwPromise<class_NetwPromise>` **save**\ (\ ) :ref:`🔗<class_NetwPersistence_method_save>`

Writes the configured properties as this :ref:`NetwEntity<class_NetwEntity>`'s record. The promise returns ``false`` when nothing had changed. A failed save fails the promise, and :ref:`NetwPromise.wait()<class_NetwPromise_method_wait>` returns the code. The :ref:`NetwEntity<class_NetwEntity>` stays :ref:`dirty<class_NetwPersistence_property_dirty>` so the next save tries again.

.. code:: text

    Error
    ┠╴ERR_UNCONFIGURED  no persistence configuration or unopened database
    ┠╴ERR_UNAUTHORIZED  this peer is not the server
    ┠╴ERR_BUSY          a save is pending, the spawn load has not succeeded,
    ┃                   or the database has too many pending operations
    ┠╴ERR_INVALID_DATA  configured values have wrong types or storage gave no result
    ┠╴ERR_UNAVAILABLE   the nodes were freed, server authority changed or the
    ┃                   database closed. The write may still have reached storage
    ┖╴storage error    storage refused or could not complete the write

\ **Server Only.**
