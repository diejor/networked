NetwSimulationHandle
====================

**Inherits:** :godot:`RefCounted`

Where and how one :ref:`NetwEntity<class_NetwEntity>`'s body runs on each peer.

.. rst-class:: classref-introduction-group

Description
-----------

Reached through :ref:`NetwEntity.simulation<class_NetwEntity_property_simulation>`. Each peer runs the entity in one :ref:`mode<class_NetwSimulationHandle_property_mode>`, which decides whether :ref:`step<class_NetwSimulationHandle_property_step>` runs and whether the body is frozen. A game sets the members below and reads :ref:`mode<class_NetwSimulationHandle_property_mode>`.

\ 

An entity is simulated once it sets or calls anything here, declares :ref:`NetwPredictionHandle.archetype<class_NetwPredictionHandle_property_archetype>`, or has a :godot:`RigidBody2D` or :godot:`RigidBody3D` root drawn by :ref:`NetwEntity.interpolation<class_NetwEntity_property_interpolation>`. Other entities stay :ref:`MODE_NONE<class_NetwSimulationHandle_constant_MODE_NONE>`.



\ **Modes**\ 

The peer that authors the entity runs it as :ref:`MODE_AUTHORITY<class_NetwSimulationHandle_constant_MODE_AUTHORITY>`, and a client predicting it runs it as :ref:`MODE_PREDICT<class_NetwSimulationHandle_constant_MODE_PREDICT>`. Every other copy is a frozen :ref:`MODE_PROXY<class_NetwSimulationHandle_constant_MODE_PROXY>`, unless :ref:`replicas<class_NetwSimulationHandle_property_replicas>` or a selection makes it :ref:`MODE_ACTIVE<class_NetwSimulationHandle_constant_MODE_ACTIVE>`.



\ **Selection**\ 

While this entity runs here as :ref:`MODE_AUTHORITY<class_NetwSimulationHandle_constant_MODE_AUTHORITY>` or :ref:`MODE_PREDICT<class_NetwSimulationHandle_constant_MODE_PREDICT>`, it can pick other entities to run here as :ref:`MODE_ACTIVE<class_NetwSimulationHandle_constant_MODE_ACTIVE>`. :ref:`simulate()<class_NetwSimulationHandle_method_simulate>` names one. :ref:`simulate_nearest()<class_NetwSimulationHandle_method_simulate_nearest>`, :ref:`simulate_within()<class_NetwSimulationHandle_method_simulate_within>` and :ref:`simulate_all()<class_NetwSimulationHandle_method_simulate_all>` set a policy, and each call replaces the last.

    func _ready() -> void:

        entity.simulation.simulate_nearest(2, &"arena")

When a body of this entity runs here as :ref:`MODE_AUTHORITY<class_NetwSimulationHandle_constant_MODE_AUTHORITY>` and touches a free entity that also sets it, this peer claims that entity with :ref:`NetwEntity.HOLD_YIELDABLE<class_NetwEntity_constant_HOLD_YIELDABLE>`.
