NetwEndpoint
============

**Inherits:** :godot:`RefCounted`

A server a player can join, listed in :ref:`NetwConnection.endpoints<class_NetwConnection_property_endpoints>`.

.. rst-class:: classref-introduction-group

Description
-----------

The same row is always the same **NetwEndpoint**, so it can be compared with ``==`` and used as a :godot:`Dictionary` key.

::

    var endpoint: NetwEndpoint

    func bind(row: NetwEndpoint) -> void:
        endpoint = row
        endpoint.changed.connect(on_changed)
        on_changed()

    func on_changed() -> void:
        name_label.text = endpoint.display_name
        players_label.text = str(endpoint.info.players)
        dot.modulate = STATUS_COLORS[endpoint.status]
