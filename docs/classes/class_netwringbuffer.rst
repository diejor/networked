NetwRingBuffer
==============

**Inherits:** :godot:`RefCounted`

Stores values by tick, with a fixed capacity.

.. rst-class:: classref-introduction-group

Description
-----------

Keeps the most recent values. Recording past its capacity removes the oldest.

::

    var history := NetwRingBuffer.create(32)
    history.record(tick, snapshot)
    var exact := history.get_at(tick)
    var pair := history.bracketing_ticks(render_tick)
