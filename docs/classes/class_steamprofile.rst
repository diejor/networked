SteamProfile
============

**Inherits:** :godot:`RefCounted`

A Steam user's name, avatar and game, as the player sees them, from :ref:`SteamSocial.profile()<class_SteamSocial_method_profile>`.

.. rst-class:: classref-introduction-group

Description
-----------

Every property reads what Steam knows now, and :ref:`changed<class_SteamProfile_signal_changed>` tells when to read again. The same object stands for the same user, so a friend row keeps one and redraws on :ref:`changed<class_SteamProfile_signal_changed>`.

::

    func show_friend(id: int) -> void:
        friend = steam.profile(id)
        friend.changed.connect(_on_friend_changed)
        _on_friend_changed()

    func _on_friend_changed() -> void:
        name_label.text = friend.display_name
        avatar_rect.texture = friend.avatar
