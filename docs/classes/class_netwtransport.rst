NetwTransport
=============

**Inherits:** :godot:`RefCounted`

Extend it so :ref:`NetwConnectHandle<class_NetwConnectHandle>` can create, list and check servers for your own :godot:`MultiplayerPeer` class.

.. rst-class:: classref-introduction-group

Description
-----------

A transport creates peers of one :godot:`MultiplayerPeer` class, lists servers, and checks a server without joining it. Register it with :ref:`NetwConnectHandle.register_transport()<class_NetwConnectHandle_method_register_transport>`. For WebRTC, see :ref:`NetwWebRTCSignaler<class_NetwWebRTCSignaler>`.

::

    class_name RelayTransport
    extends NetwTransport

    func _peer_class() -> StringName:
        return &"RelayMultiplayerPeer"

    func _host_settings() -> Dictionary:
        return {region = "eu"}

    func _make_peer(
            ticket: RID, mode: NetwMultiplayer.TransportMode,
            address: String, settings: Dictionary) -> void:
        report(ticket, &"handshake", "Reaching the relay...", 0.5)
        var peer := RelayMultiplayerPeer.new()
        var err: Error = await peer.connect_async(address, settings.region)
        if err != OK:
            fail(ticket, ERR_CANT_CONNECT, "relay rejected")
            return
        _room = peer.room
        deliver(ticket, peer)

    func _join_address() -> String:
        return _room

    # somewhere in the game
    func _ready() -> void:
        Netw.connection(self).register_transport(RelayTransport)

\ :ref:`_make_peer()<class_NetwTransport_private_method__make_peer>` and :ref:`_probe()<class_NetwTransport_private_method__probe>` may ``await``. They report the result by calling :ref:`deliver()<class_NetwTransport_method_deliver>`, :ref:`deliver_probe()<class_NetwTransport_method_deliver_probe>` or :ref:`fail()<class_NetwTransport_method_fail>` once, with the ``ticket`` they received. Keep ``ticket`` in a local variable, not a member, since another request may start while one awaits. With no report, the request fails after :ref:`_timeout_hint()<class_NetwTransport_private_method__timeout_hint>` seconds.

Methods starting with an underscore are overridden. Each has a public method that calls it, and a ``_default`` method with the default behavior.

.. _class_NetwTransport_private_method__make_peer:

.. rst-class:: classref-method

|void| **_make_peer**\ (\ ticket\: :godot:`RID`, mode\: :ref:`TransportMode<enum_NetwMultiplayer_TransportMode>`, address\: :godot:`String`, settings\: :godot:`Dictionary`\ ) |virtual| :ref:`🔗<class_NetwTransport_private_method__make_peer>`

Create a peer, then call :ref:`deliver()<class_NetwTransport_method_deliver>` or :ref:`fail()<class_NetwTransport_method_fail>` with ``ticket``. :ref:`NetwMultiplayer.TRANSPORT_MODE_HOST<class_NetwMultiplayer_constant_TRANSPORT_MODE_HOST>` creates a server from ``settings``. :ref:`NetwMultiplayer.TRANSPORT_MODE_CLIENT<class_NetwMultiplayer_constant_TRANSPORT_MODE_CLIENT>` creates a client that joins ``address``.

Deliver the peer while it is still connecting, without waiting for it to connect. When hosting fails because the port is taken, fail with :godot:`@GlobalScope.ERR_ALREADY_IN_USE <@GlobalScope#class_@GlobalScope_constant_ERR_ALREADY_IN_USE>`. The default fails with :godot:`@GlobalScope.ERR_UNCONFIGURED <@GlobalScope#class_@GlobalScope_constant_ERR_UNCONFIGURED>`.

.. _class_NetwTransport_method_publish_targets:

.. rst-class:: classref-method

|void| **publish_targets**\ (\ addresses\: :godot:`PackedStringArray`, names\: :godot:`PackedStringArray` = PackedStringArray(), infos\: :godot:`Array` = []\ ) :ref:`🔗<class_NetwTransport_method_publish_targets>`

Reports the servers :ref:`_browse()<class_NetwTransport_private_method__browse>` found, one per address. ``names`` and ``infos`` are matched to ``addresses`` by index, and can be shorter.

::

    func _browse() -> void:
        var lobbies := await _sdk.search()
        var addresses := PackedStringArray()
        var names := PackedStringArray()
        var infos: Array[NetwServerInfo] = []
        for lobby in lobbies:
            addresses.append(lobby.id)
            names.append(lobby.name)
            infos.append(_info_of(lobby))
        publish_targets(addresses, names, infos)
