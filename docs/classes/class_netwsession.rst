NetwSession
===========

**Inherits:** :godot:`RefCounted`

The players, scenes and signals of a :godot:`Node.multiplayer <Node#class_Node_property_multiplayer>` session.

.. rst-class:: classref-introduction-group

Description
-----------

Reached with :ref:`Netw.session()<class_Netw_method_session>` from any :godot:`Node`. Mostly useful for connecting signals.

::

    var s := Netw.session(self)
    s.entered.connect(on_entered)
    s.exited.connect(on_exited)
    for player: NetwPlayer in s.players:
        scoreboard.add(player)

    func on_exited(reason: NetwSession.ExitReason, detail: String) -> void:
        if reason == NetwSession.KICKED:
            show_message("Kicked: %s" % detail)

\ There is one handle per session, so it is safe to keep it across an await.

Connecting is done as you would normally do with :godot:`SceneMultiplayer`, by assigning :godot:`MultiplayerAPI.multiplayer_peer <MultiplayerAPI#class_MultiplayerAPI_property_multiplayer_peer>`. :ref:`connection<class_NetwSession_property_connection>` finds servers and joins or hosts one, and :ref:`Netw.prepare_join()<class_Netw_method_prepare_join>` names the player who joins.

\ **Moving the server**\ 

The session survives the server leaving when its :godot:`MultiplayerPeer` can hand the server role to another peer. Such a peer declares this signal, and :ref:`transfer_server()<class_NetwSession_method_transfer_server>` works when it also has the method.

::

    signal server_relabelled(successor_was: int, former_now: int)

    func transfer_server(peer_id: int) -> Error:
        pass

\ The peer emits the signal from its own :godot:`MultiplayerPeer.poll() <MultiplayerPeer#class_MultiplayerPeer_method_poll>`, once it already answers the new ids. :ref:`NakamaWrapper<class_NakamaWrapper>` does this when :ref:`NakamaWrapper.migrate_on_host_loss<class_NakamaWrapper_property_migrate_on_host_loss>` is on. ENet, WebRTC, Steam and :godot:`OfflineMultiplayerPeer` do not, so losing the server ends the session.

.. _class_NetwSession_signal_server_transferred:

.. rst-class:: classref-signal

**server_transferred**\ (\ successor_was\: :godot:`int`, former_now\: :godot:`int`\ ) :ref:`🔗<class_NetwSession_signal_server_transferred>`

Emitted on every peer once the peer that was ``successor_was`` has become the server at id ``1``, and the old server, if it stayed, has become ``former_now``.

\ ``former_now`` is ``0`` when the old server is gone, and its player leaves after this signal.


.. tabs::

 .. code-tab:: gdscript

    func _ready() -> void:
        Netw.session(self).server_transferred.connect(on_server_transferred)

    func on_server_transferred(successor_was: int, former_now: int) -> void:
        scoreboard.rename(successor_was, 1)
        if former_now != 0:
            scoreboard.rename(1, former_now)

The :ref:`NetwPlayer<class_NetwPlayer>` with :ref:`NetwPlayer.account<class_NetwPlayer_property_account>` equal to ``account``, or ``null``. It answers a player currently in the session, so an admission handler can kick a player already signed in with that account. A client knows only its own account, so on a client it answers the local player or ``null``.

::

    func admit(request: NetwJoinRequest) -> Error:
        var signed_in := session.find_player(request.account)
        if signed_in != null:
            session.kick(signed_in, "Signed in somewhere else.")
        return OK

.. _class_NetwSession_method_save_entities:

.. rst-class:: classref-method

:ref:`NetwPromise<class_NetwPromise>` **save_entities**\ (\ ) :ref:`🔗<class_NetwSession_method_save_entities>`

Saves every entity row that changed since its last save, including rows of entities that already left. Call it again to retry a row the database refused. :ref:`leave()<class_NetwSession_method_leave>` runs the same save.

.. code:: text

    Error
    ┠╴OK                every changed row is stored
    ┠╴ERR_UNAUTHORIZED  this peer is not the server
    ┠╴ERR_UNCONFIGURED  this handle outlived its session
    ┖╴a row's code      the first row still unsaved, see NetwPersistence.save

\ **Server Only.**

:godot:`Error <@GlobalScope#enum_@globalscope_Error>` **transfer_server**\ (\ peer_id\: :godot:`int`\ ) :ref:`🔗<class_NetwSession_method_transfer_server>`

Asks the transport to make ``peer_id`` the server and this peer a client under a new id. :ref:`server_transferred<class_NetwSession_signal_server_transferred>` follows on every peer. Whether a transport can is stated in the class description.

    ┠╴ERR_INVALID_PARAMETER   peer_id is not a connected client
    ┖╴ERR_BUSY                a database still has writes to settle

\ **Server Only.**
