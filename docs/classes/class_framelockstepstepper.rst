FrameLockstepStepper
====================

**Inherits:** :godot:`RefCounted`

Drives clocked peers tick by tick, pumping real physics frames at each clock's natural physics-to-tick ratio.

.. rst-class:: classref-introduction-group

Description
-----------

Like :godot:`LockstepStepper` it owns ticking through :ref:`NetwMultiplayer.CLOCK_PARAM_MANUAL_TICK<class_NetwMultiplayer_constant_CLOCK_PARAM_MANUAL_TICK>` and :ref:`NetwMultiplayer.clock_step()<class_NetwMultiplayer_method_clock_step>`, so the tick count is exact with no dependence on wall-clock accumulation or :godot:`Engine. time_scale <Engine#class_Engine_property_ time_scale>`. Unlike :godot:`LockstepStepper` it runs real :godot:`SceneTree. physics_frame <SceneTree#class_SceneTree_signal_ physics_frame>`\ s before each step, so frame coupled work still happens: input sampled in ``_physics_process``, :godot:`CharacterBody2D. move_and_slide() <CharacterBody2D#class_CharacterBody2D_method_ move_and_slide>`, and visual interpolation in ``_process``.  A clock at :ref:`NetwMultiplayer.CLOCK_PARAM_TICKRATE<class_NetwMultiplayer_constant_CLOCK_PARAM_TICKRATE>` below :godot:`Engine. physics_ticks_per_second <Engine#class_Engine_property_ physics_ticks_per_second>` naturally ticks once every several physics frames. The stepper honors that ratio so a stepped scene runs at the game's real cadence: per-frame work (a physics-mode :godot:`AnimationPlayer` fuse) and per-tick work (a tick-paced body) stay in wall-clock proportion instead of collapsing to one frame per tick. 

::

    physics_ticks_per_second = 60, tickrate = 15  →  ratio 4

    frame: 1   2   3   4   5   6   7   8
                       ^               ^
                     tick 1          tick 2

\ Use this for full game scenes that sample input and integrate physics through the engine. Use :godot:`LockstepStepper` when input is injected straight into the timeline and no frames are needed. 

::

    var stepper := FrameLockstepStepper.new(
        get_tree(),
        [server_session, client_session],
    )
    await stepper.sync_ticks(8)   # 8 ticks at each clock's physics:tick ratio

|void| **sync_ticks**\ (\ ticks\: :godot:`int`\ ) :ref:`🔗<class_FrameLockstepStepper_method_sync_ticks>`

Advances every clock by exactly ``ticks`` ticks. Each clock force steps once every ``physics_ticks_per_second / tickrate`` physics frames, so a low-tickrate clock advances at its real wall-clock pace while the shared physics-frame stream keeps frame-coupled work moving. :ref:`NetwMultiplayer.CLOCK_PARAM_MANUAL_TICK<class_NetwMultiplayer_constant_CLOCK_PARAM_MANUAL_TICK>` is held only for the duration of the call, so the real tick loop resumes between calls and connection-phase resumes between calls and connection-phase handshakes keep ticking.
