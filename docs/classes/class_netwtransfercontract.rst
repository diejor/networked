NetwTransferContract
====================

**Inherits:** :godot:`RefCounted`

The laws a :godot:`MultiplayerPeer` that hands the server role on must meet.

.. rst-class:: classref-introduction-group

Description
-----------

Each scenario mounts one :godot:`SceneMultiplayer` per endpoint a :ref:`NetwTransferDriver<class_NetwTransferDriver>` builds, and each broken law is reported as a ``"law x scenario: detail"`` line.

::

    var contract := NetwTransferContract.new(MyDriver.new(), node)
    var failures := contract.run()
    assert(failures.is_empty(), "\n".join(failures))



\ - **C1** no endpoint relays, and every survivor reaches every other. 

- **C2** every survivor installs the same transfer once. 

- **C3** an endpoint answers its new id inside the signal. 

- **C4** a packet is read only under its sender's transfers. 

- **C5** no peer edge is emitted for a relabelled id. 

- **C6** every survivor stays connected. 

- **C7** no id is handed out twice. 

- **C8** a joiner is refused, or completes under the new labels. 

- **inner** a :godot:`SceneMultiplayer` reset inside the signal stays whole.
