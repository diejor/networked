NetwAccountProvider
===================

**Inherits:** :godot:`RefCounted`

**Inherited By:** :ref:`NetwIdToken<class_NetwIdToken>`, :ref:`SteamTicket<class_SteamTicket>`

Proves one kind of player account to the server when the player joins.

.. rst-class:: classref-introduction-group

Description
-----------

Accept the same providers in the same order on every peer with :ref:`NetwAdmissionConfig.accept()<class_NetwAdmissionConfig_method_accept>`. The joining peer runs :ref:`_prove()<class_NetwAccountProvider_private_method__prove>` for each one, then the server runs :ref:`_verify()<class_NetwAccountProvider_private_method__verify>` for each one, before the admission handler sees the :ref:`NetwJoinRequest<class_NetwJoinRequest>`.

::

    class_name PasscodeAccount
    extends NetwAccountProvider

    func _prove(challenge: String, _session: NetwSession) -> Variant:
        return (PASSCODE + challenge).sha256_text()

    func _verify(request: NetwJoinRequest, proof: Variant) -> Variant:
        if proof is String and proof == (PASSCODE + request.challenge).sha256_text():
            request.add_account("club:" + request.username, request.username)
        return OK

\ Proving and verifying count against :ref:`NetwMultiplayer.auth_timeout<class_NetwMultiplayer_property_auth_timeout>`. :ref:`NetwIdToken<class_NetwIdToken>` is a ready provider for signed tokens.
