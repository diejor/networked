NetwAction
==========

**Inherits:** :godot:`RefCounted`

A predicted discrete action bound to one authority method.

.. rst-class:: classref-introduction-group

Description
-----------

Shows the result of an action right away on the client that asked for it, then keeps or removes it once the server answers. Create one with :ref:`Netw.action()<class_Netw_method_action>`.

::

    @onready var place_bomb := Netw.action(_place_bomb)

    func _ready() -> void:
        place_bomb.predict = _predict_bomb

    func _network_tick(delta, tick, is_fresh) -> void:
        if is_fresh and inputs.bombing:
            place_bomb.request(tick)

    func _place_bomb(ctx: NetwActionContext) -> void:
        var bomb := BOMB.instantiate()
        ctx.bind(bomb)
        $Bombs.add_child(bomb)

|void| **request**\ (\ view_tick\: :godot:`int`, ...\ ) |vararg| :ref:`🔗<class_NetwAction_method_request>`

Asks the server to run the action at ``view_tick``. Every argument after ``view_tick`` reaches that method in the order it was written, after the :ref:`NetwActionContext<class_NetwActionContext>` the method always takes first.

::

    place_bomb.request(tick, position, fuse)

    func _place_bomb(ctx: NetwActionContext, pos: Vector2, fuse: float) -> void:

\ On the peer controlling the entity, :ref:`predict<class_NetwAction_property_predict>` runs immediately. On any other peer the call does nothing.

\ **Player request.**
