NetwReparentOpts
================

**Inherits:** :godot:`RefCounted`

Reason metadata for one :ref:`NetwEntity.reparent_to()<class_NetwEntity_method_reparent_to>` call.

.. rst-class:: classref-introduction-group

Description
-----------

The destination is passed to :ref:`NetwEntity.reparent_to()<class_NetwEntity_method_reparent_to>`.

This object carries the reason reported with the move.

::

    var opts := NetwReparentOpts.new()
    opts.reason = &"boarded"
    NetwEntity.of(self).reparent_to(next_room, opts)
