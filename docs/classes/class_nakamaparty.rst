NakamaParty
===========

**Inherits:** :godot:`RefCounted`

The player's party of Nakama friends, which stays together across matches and servers.

.. rst-class:: classref-introduction-group

Description
-----------

A signed in player is in a party of one, leading it, until a friend joins. Each :ref:`NakamaAccount<class_NakamaAccount>` has one as :ref:`NakamaAccount.party<class_NakamaAccount_property_party>`. 

An invitation and a join request both reach a friend through ``server/networked.js``, which the Nakama server must run. 

Only the leader invites, kicks and queues for a match, because Nakama sends every join request to the leader. 

Each member follows the leader's server through :ref:`NetwConnection.invited<class_NetwConnection_signal_invited>`, and :ref:`find_match()<class_NakamaParty_method_find_match>` queues the whole party in Nakama's matchmaker.

::

    @onready var nakama: NakamaAccount = session.service(NakamaAccount)

    func _ready() -> void:
        nakama.party.invited.connect(_on_party_invited)
        session.connection.invited.connect(_on_invited)

    func _on_invite_pressed(user_id: String) -> void:
        nakama.party.invite(user_id)

    func _on_party_invited(friend: String) -> void:
        invitation.show_from(friend)

    func _on_accept_pressed() -> void:
        nakama.party.join(invitation.friend)

    func _on_find_match_pressed() -> void:
        nakama.party.find_match(2, 8)

    func _on_invited(endpoint: NetwEndpoint) -> void:
        await session.connection.join(endpoint).settled

.. _class_NakamaParty_method_find_match:

.. rst-class:: classref-method

|void| **find_match**\ (\ minimum\: :godot:`int`, maximum\: :godot:`int`, query\: :godot:`String` = "*"\ ) :ref:`🔗<class_NakamaParty_method_find_match>`
