NetwEntity
==========

**Inherits:** :godot:`RefCounted`

The identity of one networked node, player or server-owned.

.. rst-class:: classref-introduction-group

Description
-----------

One networked entity is one root node holding one **NetwEntity**. Nodes under the root read it to learn who the entity is, who controls it, and when it spawns and despawns.

::

    NetwEntity.of(node)         # walks up to the entity, null when there is none
    Netw.configure_entity(self) # gets or creates it on a root, in _init

\ :ref:`controller<class_NetwEntity_property_controller>` and :ref:`authority<class_NetwEntity_property_authority>` are settled before the node enters the tree, so :ref:`is_controlled_locally<class_NetwEntity_property_is_controlled_locally>` and :godot:`Node.is_multiplayer_authority() <Node#class_Node_method_is_multiplayer_authority>` are already correct in :godot:`Node._enter_tree() <Node#class_Node_private_method__enter_tree>` and :godot:`Node._ready() <Node#class_Node_private_method__ready>` on every peer.

::

    var entity := NetwEntity.of(hit_node)
    if entity and entity.is_player:
        eliminate(entity.peer_id)

\ **Declaring an entity**\ 

A root declares itself in ``_init``. A child marks its own spawn properties in its ``_init`` and connects to the entity in :godot:`Node._ready() <Node#class_Node_private_method__ready>`, once it has a parent to walk up to.

::

    # on the root
    func _init() -> void:
        var entity := Netw.configure_entity(self)
        entity.initial_controller = NetwEntity.INITIAL_PLAYER
        entity.spawned.connect(_on_spawned)
        Netw.configure_property(self, &"position").on_spawn()

    # on a child
    func _init() -> void:
        Netw.configure_property(self, &"health").on_spawn()

    func _ready() -> void:
        NetwEntity.of(self).despawning.connect(_on_despawning)

\ A node placed in a scene by hand sets its own :ref:`name<class_NetwEntity_property_name>`. A spawned copy receives it with the spawn.

::

    func _init() -> void:
        Netw.configure_entity(self).name = &"ball"

\ **Control and authority**\ 

\ :ref:`AUTHORITY_SERVER<class_NetwEntity_constant_AUTHORITY_SERVER>` keeps Godot multiplayer authority on the server while :ref:`controller<class_NetwEntity_property_controller>` steers. :ref:`AUTHORITY_CONTROLLER<class_NetwEntity_constant_AUTHORITY_CONTROLLER>` moves Godot authority with control. Properties configured with :ref:`NetwPropertyConfig.state()<class_NetwPropertyConfig_method_state>` are server-written in both modes.

\ :ref:`NetwSimulation.claim_on_contact<class_NetwSimulation_property_claim_on_contact>` and :ref:`NetwSimulation.release_on_rest<class_NetwSimulation_property_release_on_rest>` let a body take control of what it touches and hand it back once it rests.

\ **Letting the controller spawn and despawn**\ 

Only the server spawns, moves and despawns an entity by default. When :ref:`lifecycle<class_NetwEntity_property_lifecycle>` is :ref:`LIFECYCLE_CONTROLLER<class_NetwEntity_constant_LIFECYCLE_CONTROLLER>` the :ref:`controller<class_NetwEntity_property_controller>` may too, and the change shows on its screen at once. The server can refuse it in :ref:`lifecycle_requested<class_NetwEntity_signal_lifecycle_requested>`, and the change is then undone on the controller.

::

    func _init() -> void:
        Netw.configure_entity(self).lifecycle = NetwEntity.LIFECYCLE_CONTROLLER

\ **Simulation**\ 

\ :ref:`simulation<class_NetwEntity_property_simulation>` says how the entity's body runs on each peer, :ref:`prediction<class_NetwEntity_property_prediction>` how a controller runs it ahead, and :ref:`display<class_NetwEntity_property_display>` how it is drawn.

::

    func _init() -> void:
        var entity := Netw.configure_entity(self)
        entity.simulation.replicas = NetwSimulation.REPLICAS_ACTIVE
        entity.prediction.archetype = NetwPrediction.ARCHETYPE_SOLVER_BODY

.. _class_NetwEntity_method_claim_control:

.. rst-class:: classref-method

:ref:`NetwPromise<class_NetwPromise>` **claim_control**\ (\ hold\: :ref:`Hold<enum_NetwEntity_Hold>` = 2\ ) :ref:`🔗<class_NetwEntity_method_claim_control>`

Asks the server to make this peer the :ref:`controller<class_NetwEntity_property_controller>` with ``hold``. The returned :ref:`NetwPromise<class_NetwPromise>` resolves with this entity once the decision reaches this peer.

.. code:: text

    Error
    ┠╴ERR_UNAUTHORIZED   another peer's hold or control_requested refused it
    ┠╴ERR_UNAVAILABLE    transfer does not allow a claim, or it is
    ┃                    TRANSFER_IMMEDIATE on an entity with a state()
    ┃                    property, prediction or a MultiplayerSynchronizer
    ┖╴ERR_TIMEOUT        no decision arrived within one second

\ Under :ref:`TRANSFER_IMMEDIATE<class_NetwEntity_constant_TRANSFER_IMMEDIATE>` this peer runs the node before the decision. A refusal restores the controller's latest values.

::

    entity.claim_control(NetwEntity.HOLD_YIELDABLE) \
        .then(func(_held: NetwEntity) -> void: pick_up()) \
        .catch_error(func(_code: Error, _detail: String) -> void: shrug())

\ **Player request.**

.. _class_NetwEntity_method_despawn:

|void| **despawn**\ (\ opts\: :ref:`NetwDespawnOpts<class_NetwDespawnOpts>` = null\ ) :ref:`🔗<class_NetwEntity_method_despawn>`

Frees :ref:`owner<class_NetwEntity_property_owner>` after emitting :ref:`despawning<class_NetwEntity_signal_despawning>` and saving its :ref:`persistence<class_NetwEntity_property_persistence>`. Entities under it despawn too, unless their :ref:`on_parent_despawn<class_NetwEntity_property_on_parent_despawn>` is :ref:`PARENT_DESPAWN_DETACH<class_NetwEntity_constant_PARENT_DESPAWN_DETACH>`.

.. _class_NetwEntity_method_release_control:

.. rst-class:: classref-method

:ref:`NetwPromise<class_NetwPromise>` **release_control**\ (\ successor\: :godot:`int` = 1\ ) :ref:`🔗<class_NetwEntity_method_release_control>`

Hands control of this entity to ``successor``, which is the server by default. The returned :ref:`NetwPromise<class_NetwPromise>` resolves with this entity once the decision reaches this peer.

The request carries this peer's latest :ref:`NetwPropertyConfig.broadcast()<class_NetwPropertyConfig_method_broadcast>` values, and ``successor`` starts from them. Values larger than 1024 bytes are not sent, and ``successor`` starts from its own copy.

.. code:: text

    Error
    ┠╴ERR_INVALID_PARAMETER   successor is not a peer id
    ┠╴ERR_UNAUTHORIZED        this peer neither controls the entity nor is claiming it
    ┖╴ERR_UNAVAILABLE         successor holds no copy of the entity
