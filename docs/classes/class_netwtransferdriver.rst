NetwTransferDriver
==================

**Inherits:** :godot:`RefCounted`

The transport a :ref:`NetwTransferContract<class_NetwTransferContract>` judges, subclassed by its author.

.. rst-class:: classref-introduction-group

Description
-----------

Every endpoint declares ``server_relabelled(successor_was: int, former_now: int)`` and installs a transfer from inside its own :godot:`MultiplayerPeer.poll() <MultiplayerPeer#class_MultiplayerPeer_method_poll>`.

::

    class MyDriver extends NetwTransferDriver:
        func make_endpoints(count: int) -> Array[MultiplayerPeer]:
            return MyPeer.mesh(count)

        func lose_server() -> void:
            MyPeer.crash_server()

    var failures := NetwTransferContract.new(MyDriver.new(), node).run()
