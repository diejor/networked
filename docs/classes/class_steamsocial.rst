SteamSocial
===========

**Inherits:** :ref:`NetwService<class_NetwService>` **<** :godot:`Node`

Connects the player with their Steam friends and lets them join the player's session from Steam.

.. rst-class:: classref-introduction-group

Description
-----------


::

    @onready var steam: SteamSocial = session.service(SteamSocial)

    func _ready() -> void:
        for friend in steam.friends:
            friends_list.add_item(steam.profile(friend).display_name)
        session.connection.invited.connect(_on_invited)

    func _on_friends_list_item_activated(index: int) -> void:
        steam.invite_friend(steam.friends[index])

    func _on_invited(endpoint: NetwEndpoint) -> void:
        await session.connection.join(endpoint).settled

\ With two sessions in one game, such as split screen, only the first **SteamSocial** to enter the tree handles Steam invites and runs :ref:`party<class_SteamSocial_property_party>`, because Steam signs in one player per game.
