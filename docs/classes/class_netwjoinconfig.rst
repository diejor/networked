NetwJoinConfig
==============

**Inherits:** :godot:`RefCounted`

Settings for the join handler, returned by :ref:`Netw.configure_join()<class_Netw_method_configure_join>`.

.. rst-class:: classref-introduction-group

Description
-----------

:ref:`quantize()<class_NetwJoinConfig_method_quantize>` compresses the arguments a client passes to :ref:`Netw.prepare_join()<class_Netw_method_prepare_join>` after its username. The first quantizer is for the second parameter of the handler, after its :ref:`NetwPlayer<class_NetwPlayer>`.

::

    func _init() -> void:
        Netw.configure_join(spawn_at) \
                .quantize(null, NetwQuantizeScalar.new().bits(4).limits(0, 8))

    func spawn_at(who: NetwPlayer, point: StringName, team: int) -> void:
        ...

:ref:`NetwJoinConfig<class_NetwJoinConfig>` **quantize**\ (\ ...\ ) |vararg| :ref:`🔗<class_NetwJoinConfig_method_quantize>`

Compresses each join argument with one :ref:`NetwQuantize<class_NetwQuantize>`, in order. ``null`` sends an argument as is. The number of quantizers must match the number of arguments. Returns this config.
