:godot:`Dictionary` **start**\ (\ app_id\: :godot:`int`\ ) |static| :ref:`🔗<class_addons_networked_steam_steam_start_gd_method_start>`

Starts Steam once per process with ``app_id``, or reads how it started. Returns GodotSteam's start result, whose ``status`` is ``0`` once Steam runs.
