:godot:`bool` **timeout**\ (\ target_signal\: :godot:`Signal`, timer\: :godot:`SceneTreeTimer`\ ) |static| :ref:`🔗<class_addons_networked_gdscript_async_gd_method_timeout>`

Awaits ``target_signal`` and aborts early if ``timer`` expires first.  Returns ``true`` if the timer fired before the signal. Returns ``false`` if the signal fired in time.

::

    var timer := get_tree().create_timer(5.0)
    if await Async.timeout(my_signal, timer):
        push_error("Timed out waiting for my_signal.")
