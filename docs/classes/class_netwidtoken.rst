NetwIdToken
===========

**Inherits:** :ref:`NetwAccountProvider<class_NetwAccountProvider>` **<** :godot:`RefCounted`

**Inherited By:** :ref:`NakamaIdToken<class_NakamaIdToken>`

Proves an account with a signed token from an issuer the server trusts, such as a game's own backend.

.. rst-class:: classref-introduction-group

Description
-----------

The token's nonce names a key the joining peer keeps, and that key signs each server's challenge, so one token serves every join until it expires. The server needs no secret, only :ref:`key<class_NetwIdToken_property_key>` or :ref:`keys_url<class_NetwIdToken_property_keys_url>`.

::

    const ISSUER := "https://api.mygame.com"

    func _init() -> void:
        var token := NetwIdToken.new()
        token.issuer = ISSUER
        token.audience = "my-game"
        token.prefix = "mygame"
        token.key = load("res://backend.pub")
        Netw.configure_admission(admit).accept(token)
        NetwIdToken.provide(ISSUER, fetch_token)

    func fetch_token(nonce: String) -> NetwPromise:
        return backend.request_join_token(nonce)

    func admit(request: NetwJoinRequest) -> Error:
        return OK if request.account else ERR_UNAUTHORIZED
