WebTorrentLobbyDirectory
========================

**Inherits:** :ref:`LobbyDirectory<class_LobbyDirectory>` **<** :ref:`NetwService<class_NetwService>` **<** :godot:`Node`

Lists WebRTC rooms on WebTorrent trackers.

.. rst-class:: classref-introduction-group

Description
-----------

A host is listed while its session is the server of a WebRTC room and its :ref:`NetwServerInfo<class_NetwServerInfo>` is :ref:`NetwServerInfo.VISIBILITY_PUBLIC<class_NetwServerInfo_constant_VISIBILITY_PUBLIC>`. Joining a listed room goes through the WebRTC transport.

Without this node nothing is listed or browsed, and a room is still joined by its code. A room signaled through a game's own :ref:`NetwWebRTCSignaler<class_NetwWebRTCSignaler>` is never listed.

Rooms are searched in the ``signaling_namespace`` of those same defaults, or in :ref:`NetwSessionConfig.app_id<class_NetwSessionConfig_property_app_id>` when it is empty.
