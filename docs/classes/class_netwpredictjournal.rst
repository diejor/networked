NetwPredictJournal
==================

**Inherits:** :godot:`RefCounted`

Packed-column snapshot of the transitions a prediction engine drove.

.. rst-class:: classref-introduction-group

Description
-----------

Production ownership stays in the native engine. A caller never builds

one up: :ref:`NetwPredictionHandle.journal()<class_NetwPredictionHandle_method_journal>` materializes this

tooling-cadence view without changing the retained native rows, and

\ ``NetwPredictJournal.new()`` itself yields an empty

snapshot with :ref:`size()<class_NetwPredictJournal_method_size>` zero. A closed row names one drive completely.

A row is a complete account of the transition it names, so a

transition is reproducible from its row alone. Nothing the engine

decided is held outside the row and read back later, which is what

lets two peers compare transitions instead of comparing engines.

Two peers that ran the same transition closure agree on

\ :ref:`post_fps()<class_NetwPredictJournal_method_post_fps>` at every acked transition, and the first transition where

they disagree is the one that broke, not the one where the error grew

visible.

A native enum is not a :godot:`Dictionary` at runtime the way a GDScript enum

is, so :ref:`attribution_names()<class_NetwPredictJournal_method_attribution_names>`, :ref:`operator_names()<class_NetwPredictJournal_method_operator_names>`,

\ :ref:`domain_names()<class_NetwPredictJournal_method_domain_names>`, and :ref:`state_family_names()<class_NetwPredictJournal_method_state_family_names>` exist for a caller

that wants a name for a stored value rather than the bare

\ :ref:`Attribution<enum_NetwPredictJournal_Attribution>`, :ref:`Operator<enum_NetwPredictJournal_Operator>`, :ref:`Domain<enum_NetwPredictJournal_Domain>`, or :ref:`StateFamily<enum_NetwPredictJournal_StateFamily>`.

::

    var journal := entity.prediction.journal()
    var transitions := journal.transitions()
    var flags := journal.flags()
    for i in transitions.size():
        if flags[i] & NetwPredictJournal.ROW_DIVERGENT:
            print("diverged at transition ", transitions[i])
            break

.. rst-class:: classref-method

|void| **clear**\ (\ epoch\: :godot:`int`\ ) :ref:`🔗<class_NetwPredictJournal_method_clear>`

Drops every retained row and adopts ``epoch``.

Transitions are injective only within one epoch, so a journal

that outlives an epoch would hold two rows claiming the same

transition. Clearing is how a rewire keeps :ref:`row_at()<class_NetwPredictJournal_method_row_at>`\ 

unambiguous.

:godot:`Dictionary` **row_at**\ (\ transition\: :godot:`int`\ ) |const| :ref:`🔗<class_NetwPredictJournal_method_row_at>`

Returns the row recorded for ``transition``, or an empty

\ :godot:`Dictionary` when it has fallen out of the ring.

This is the tooling-cadence read. Bulk readers take the

columns through :ref:`transitions()<class_NetwPredictJournal_method_transitions>` and its siblings instead

of materializing a row per transition.

.. code:: text

    Dictionary
    ┠╴transition   int   the recurrence index, injective within an epoch
    ┠╴label        int   the clock label the drive carried
    ┠╴kind         int   a DriveKind value naming the command selection
    ┠╴c_hash       int   fingerprint of the canonical command bytes
    ┠╴e_digest     int   fingerprint of the declared environment facts
    ┠╴post_fp      int   fingerprint of the state the drive produced
    ┠╴domain       int   a Domain value
    ┠╴attribution  int   an Attribution value
    ┖╴flags        int   the ROW_ bitfield

\ The row also exposes ``pre_fp``, the pre and post

\ ``pose_fp``, ``momentum_fp``, and

\ ``controller_fp`` families, plus the preceding

operator's ``episode_id``, ``write_id``,

\ ``operator``, and ``basis``. Settled rows

expose ``aligned_error``, and witnessed rows expose

\ ``witness_class_bits``.

.. _class_NetwPredictJournal_method_topo_fps:

.. rst-class:: classref-method

:godot:`PackedInt32Array` **topo_fps**\ (\ ) |const| :ref:`🔗<class_NetwPredictJournal_method_topo_fps>`

Returns the retained execution-topology fingerprints, ordered by

\ :ref:`transitions()<class_NetwPredictJournal_method_transitions>`.

The declared quantum is folded into this hash, and nothing

else is. The quantum is how many physics steps a drive

actually bought, and it belongs here because the physics

server integrates on its own cadence: a drive and a solve are

two events, and only their ratio makes a compared transition

mean the same thing on both peers. Without it the boundary

ladder walks all the way to closure and reports that every

antecedent agreed. A different quantum is therefore a

different topology, deliberately, and two peers running the

same commands at different cadences disagree here rather

than nowhere.
