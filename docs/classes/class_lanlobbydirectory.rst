LANLobbyDirectory
=================

**Inherits:** :ref:`LobbyDirectory<class_LobbyDirectory>` **<** :ref:`NetwService<class_NetwService>` **<** :godot:`Node`

Finds ENet games on the local network without typing an address.

.. rst-class:: classref-introduction-group

Description
-----------

A host is listed while its session is the server of an :godot:`ENetMultiplayerPeer` and its :ref:`NetwServerInfo<class_NetwServerInfo>` is :ref:`NetwServerInfo.VISIBILITY_PUBLIC<class_NetwServerInfo_constant_VISIBILITY_PUBLIC>`. Each host answers with its own gameplay port, so a listed game is joined with nothing else.

Discovery uses UDP broadcast, so it does nothing on web and reaches one network interface.
