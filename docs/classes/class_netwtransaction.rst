NetwTransaction
===============

**Inherits:** :godot:`RefCounted`

The batch of writes collected inside a :ref:`NetwDatabase.transaction()<class_NetwDatabase_method_transaction>` body.

.. rst-class:: classref-introduction-group

Description
-----------

A transaction body receives one of these and queues its writes onto it. Nothing is written while the body runs: :ref:`NetwDatabase.transaction()<class_NetwDatabase_method_transaction>` commits the whole batch once the body returns, which is what makes the commit happen exactly once even when the body takes an early exit.

::

    await db.transaction(
        func(tx: NetwTransaction) -> void:
            tx.queue_upsert(&"rocks", &"rock_1", {&"health": 50})
            tx.queue_upsert(&"rocks", &"rock_2", {&"health": 75})
    ).wait()

|void| **queue_upsert**\ (\ table\: :godot:`StringName`, id\: :godot:`StringName`, data\: :godot:`Dictionary`\ ) :ref:`🔗<class_NetwTransaction_method_queue_upsert>`

Enqueues a write of ``data`` to ``id`` in ``table``. It lands through :ref:`NetwDatabaseBackend.upsert()<class_NetwDatabaseBackend_method_upsert>`, so a partial ``data`` merges into the stored record rather than replacing it.

Queueing the same ``id`` twice queues two writes, applied in order.
