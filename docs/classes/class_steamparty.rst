SteamParty
==========

**Inherits:** :godot:`RefCounted`

The player's party of Steam friends, which stays together across matches and servers.

.. rst-class:: classref-introduction-group

Description
-----------

A player is in a party of one, leading it, until a friend joins. Each :ref:`SteamSocial<class_SteamSocial>` has one as :ref:`SteamSocial.party<class_SteamSocial_property_party>`. 

A friend joins by accepting an invitation in Steam's overlay or chat, and the player joins a friend's party the same way. 

Only the leader can :ref:`kick()<class_SteamParty_method_kick>`. 

Each member follows the leader's server through :ref:`NetwConnection.invited<class_NetwConnection_signal_invited>`.

::

    func _ready() -> void:
        steam.party.invited.connect(_on_party_invited)

    func _on_friend_activated(index: int) -> void:
        steam.party.invite(steam.friends[index])

    func _on_party_invited(friend: int) -> void:
        notice.text = "%s invited you. Accept in Steam." % [
            steam.profile(friend).display_name,
        ]
