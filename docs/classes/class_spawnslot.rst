.. _class_SpawnSlot:

SpawnSlot
=========

**Inherits:** :godot:`RefCounted`

The resolved placement target for one player spawn.

.. rst-class:: classref-introduction-group

Description
-----------

A slot returns one question, "where does this player node go", and it returns it the same way whether the destination is a declared network scene or a plain branch of the tree. That is what lets a spawner be written once: it asks :ref:`for_scene()<class_SpawnSlot_method_for_scene>` for a slot and hands the player to :ref:`place_player()<class_SpawnSlot_method_place_player>`, instead of branching on whether the scene was declared.

A slot resolves at the moment it is asked for, so it is a value to use now rather than a handle to keep. A session that declares no scene under the requested stem returns a slot that :ref:`is_valid()<class_SpawnSlot_method_is_valid>` rejects, and placing into it does nothing.

::

    var slot := SpawnSlot.for_scene(Netw.of(self), &"Arena")
    if slot.is_valid():
        slot.place_player(player)

.. _class_SpawnSlot_method_for_scene:

.. rst-class:: classref-method

:ref:`SpawnSlot<class_SpawnSlot>` **for_scene**\ (\ session\: :ref:`NetwMultiplayer<class_NetwMultiplayer>`, scene_stem\: :godot:`StringName`\ ) |static| :ref:`🔗<class_SpawnSlot_method_for_scene>`

Resolves the slot for the scene ``session`` declares under ``scene_stem``.

This is the verb a spawner calls. A session declaring no such scene, and a null ``session``, both return a slot :ref:`is_valid()<class_SpawnSlot_method_is_valid>` rejects rather than an error, so a spawner asks once and tests the result.

::

    var slot := SpawnSlot.for_scene(Netw.of(self), &"Arena")
    if slot.is_valid():
        slot.place_player(player)

.. rst-class:: classref-method

|void| **place_player**\ (\ player\: :godot:`Node`\ ) :ref:`🔗<class_SpawnSlot_method_place_player>`

Puts ``player`` where this slot points. A scene slot adds it through :ref:`NetwSceneHandle.add_player()<class_NetwSceneHandle_method_add_player>` as the :ref:`NetwEntity<class_NetwEntity>` the node carries; a parent slot adds it as a plain child. An invalid slot places nothing.

:ref:`SpawnSlot<class_SpawnSlot>` **under**\ (\ parent\: :godot:`Node`\ ) |static| :ref:`🔗<class_SpawnSlot_method_under>`

Returns a slot that adds players as children of ``parent``, with no scene declaration involved. The parent is held weakly, so a slot outliving its parent reports :ref:`is_valid()<class_SpawnSlot_method_is_valid>` as ``false`` instead of placing into a freed node.
