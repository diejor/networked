NetwProcessRig
==============

**Inherits:** :godot:`RefCounted`

Spawns and supervises the child processes of a two-process regime capture.

.. rst-class:: classref-introduction-group

Description
-----------

A regime arm runs two real OS processes speaking real sockets, so the test that drives it is an orchestrator: build each child's argument list, spawn it with a controlled environment, wait for both to exit, and read the ``summary.json`` each :ref:`NetwRegimePeer<class_NetwRegimePeer>` left behind. This class is that orchestrator's process half, game-agnostic and framework-agnostic.

::

    var rig := NetwProcessRig.new()
    rig.spawn(SCENE, { "regime-role": "host", "regime-port": "31411" })
    await suite.get_tree().create_timer(5.0).timeout
    rig.spawn(SCENE, { "regime-role": "client", "regime-port": "31411" })
    var all_exited := await rig.await_exit(suite, 60.0)
    var summary := NetwProcessRig.read_summary(host_dir)

\ Children inherit the parent's environment, so :ref:`spawn()<class_NetwProcessRig_method_spawn>` takes an explicit environment map and restores the parent's values afterward: an empty value unsets, anything else sets. Instruments that read only the environment (``NETW_PREDICT_TAP``) are cleared by default so an armed parent can never silently arm its children.

:godot:`int` **spawn**\ (\ scene\: :godot:`String`, regime_args\: :godot:`Dictionary`, env\: :godot:`Dictionary` = {}\ ) :ref:`🔗<class_NetwProcessRig_method_spawn>`

Launches one headless child running ``scene`` with ``regime_args`` as ``--key=value`` user arguments. Returns the pid, or -1 when the spawn failed. ``env`` entries override the cleared-instrument defaults for this child only.

.. _class_NetwProcessRig_method_await_exit:

.. rst-class:: classref-method

:godot:`bool` **await_exit**\ (\ host\: :godot:`Node`, timeout_s\: :godot:`float`\ ) :ref:`🔗<class_NetwProcessRig_method_await_exit>`

Waits until every spawned child has exited, polling four times a second against ``timeout_s``. Returns ``false`` on timeout, with the stragglers killed so a wedged arm never leaks processes into the next one.

|void| **stop_all**\ (\ ) :ref:`🔗<class_NetwProcessRig_method_stop_all>`

Kills every child still running. :ref:`await_exit()<class_NetwProcessRig_method_await_exit>` does this on timeout, so callers only need it for early aborts.
