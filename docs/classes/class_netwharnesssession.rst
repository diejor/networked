NetwHarnessSession
==================

**Inherits:** :godot:`RefCounted`

Shared session plumbing for Networked test harnesses.

.. rst-class:: classref-introduction-group

Description
-----------

:godot:`RefCounted.session <RefCounted#class_RefCounted_property_session>` owns the in process transport. Harnesses keep their own tree construction and public flow APIs, then delegate backend, join payload, and link condition plumbing here.

.. _class_NetwHarnessSession_method_connect_tree:

.. rst-class:: classref-method

:godot:`Error <@GlobalScope#enum_@globalscope_Error>` **connect_tree**\ (\ tree\: :ref:`MultiplayerTree<class_MultiplayerTree>`, entry\: :ref:`Entry<enum_NetwHarnessSession_Entry>`, username\: :godot:`StringName` = &"", join_args\: :godot:`Array` = [], adapter\: :ref:`NetwHarnessSession.BackendAdapter<class_NetwHarnessSession_BackendAdapter>` = null\ ) :ref:`🔗<class_NetwHarnessSession_method_connect_tree>`

Brings ``tree`` online as ``entry``, the ordinary way.  ``adapter`` supplies the peer. When omitted, the loopback adapter owned by this session is used. A non-empty ``username`` is prepared through :ref:`NetwMultiplayer.session_prepare_join()<class_NetwMultiplayer_method_session_prepare_join>` BEFORE the assignment, so a client holds its hello and a host submits once its startup scenes exist. Returns when the session is online, which is the condition a caller waiting on entry actually means.  A direct peer assignment is refused while a declaration is still being authored, so this waits one frame for the deferred configuration to settle before assigning.

:godot:`int` **disconnect_tree**\ (\ tree\: :ref:`MultiplayerTree<class_MultiplayerTree>`\ ) :ref:`🔗<class_NetwHarnessSession_method_disconnect_tree>`

Takes ``tree`` offline. Marks it :godot:`MultiplayerTree.DISCONNECTING <MultiplayerTree#class_MultiplayerTree_constant_DISCONNECTING>`, flushes held inbound packets, and closes the peer. Returns the closed peer id so callers can await server unregistration. Inverse of :ref:`connect_tree()<class_NetwHarnessSession_method_connect_tree>`.
