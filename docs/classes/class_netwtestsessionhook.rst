NetwTestSessionHook
===================

**Inherits:** :godot:`GdUnitTestSessionHook`

GdUnit4 session hook that owns Networked debug state during tests.

.. rst-class:: classref-introduction-group

Description
-----------

Debugger scopes are closed after each test case so failures and early returns cannot leak state into the next test. Also baselines the SceneTree root child count and the engine's ``OBJECT_RESOURCE_COUNT`` performance monitor to surface isolation leaks.
